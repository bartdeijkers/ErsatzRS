# Support

ErsatzRS is pre-alpha and does not have user support guarantees yet.

Use these channels once the public repository is active:

- GitHub Issues for confirmed bugs with reproduction steps.
- GitHub Discussions for questions, setup help, and design discussion.
- Pull requests for concrete fixes.

Do not use security reporting channels for general help. Use
[SECURITY.md](SECURITY.md) only for vulnerabilities.

When asking for help, include:

- ErsatzRS version or commit.
- FFmpeg version.
- Operating system and deployment method.
- Relevant configuration with secrets removed.
- Logs with tokens, private paths, and media-library identifiers removed.
