# Build a manual collection from media results

Use a manual collection when you want to choose the exact media items that a
schedule may play. You can collect items while browsing one media kind or from
mixed global search results.

## Before you begin

Scan the source libraries and confirm that the intended items are available on
their **Media** pages. The [admin navigation
reference](../reference/admin-navigation.md) lists the media and collection
routes used below.

## Select the media

Choose either workflow:

- Open a page such as **Media** -> **Movies**, **TV Shows**, **Music**, or
  **Remote Streams** when the items share a media kind.
- Use **Search media** in the top bar when you need results from several media
  kinds or want to narrow them by title or metadata.

Select each required card with its selection control. Review the selection
count before applying a bulk action. When the desired items span several result
pages, add each page in a separate pass and verify the final collection once.

## Add the selection to a collection

1. Select **Add To Collection** from the bulk actions.
2. Choose an existing collection, or choose **New Collection** and enter a
   unique name.
3. Confirm with **Add To Collection**.
4. Select **View Collection** in the success notification.

The collection detail page should contain every selected available item. Run
the same workflow again to add results from another media page or search.

## Verify the scheduling source

Open **Lists** -> **Collections**, find the collection, and confirm that its
member count and cards match the intended channel content. Remove an accidental
member before building or refreshing a playout.

If **Add To Collection** is unavailable, select at least one card and wait for
the hydrated selection toolbar to appear. If a known item is missing from
search, verify its library scan and metadata before changing the collection.

Continue with [Build a channel from a
collection](build-a-channel-from-a-collection.md) when the member list is
correct.
