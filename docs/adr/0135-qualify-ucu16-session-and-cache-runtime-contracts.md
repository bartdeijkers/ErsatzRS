# ADR 0135: Qualify UCU-16 session and cache runtime contracts

## Status

Proposed 2026-11-16. The active continuation authorizes local implementation,
builds and evidence preparation for rows290–296. This proposal records the
runtime successor and compatibility boundary needed by that work. It grants no
additional commit/push, CI, publication, operator adoption or release authority.

## Implementation

Partial — row291 persisted session settings, worker-owned idle handling,
demand-driven heartbeat, bounded consumer waits and runtime admission are
implemented locally. Actual accepted025 fails the idle protocol control;
unpatched exact6c passes the four local session cases. The accepted distribution
and runtime manifest remain unchanged. R296-A now carries the application-owned
shared cache into saved normal/preview and standalone previews, selecting plain
schema0.1.5 or indexed0.1.6. Matching process admission and Health refuse an
unsuitable schema; explicit legacy configurations retain their omitted cache.
Focused configuration, refusal, legacy and preview controls pass. R296-B now
proves actual fixed-worker reuse, invalidation, retention, original-image
fallback, animation/fade/canvas preservation and bounded process cleanup within
its local Linux scope. Cache-path diagnostic redaction is also corrected.
A separate reviewed exact6c source recipe now preserves the indexed extension
with schema0.1.6 and upstream session/cache fields; local indexed/preview/cache
integration passes. Serial software and current full dependency policy also
pass; an additional scoped security patch updates the two demonstrated XML/root-
certificate dependencies while retaining unrelated inputs and all12 corrections.
Retained runtime retirement controls, required packages and integrated acceptance
remain open in the continuation milestone. The four worker packages and their
native Linux/Windows and ARM-emulated runtime controls are now qualified. The
isolated application candidate proposes their exact source/patch/archive/payload
pin for actual bundled application qualification. The C5 recipe remains archived;
both deferred macOS package identities are retained exactly. This is a private
source proposal, not main integration, publication or managed/operator adoption.
Health derives the overlay-schema ceiling from the selected runtime's existing
validated session contract:0.1.5 for plain and0.1.6 for indexed. It retains
invalid/future-schema refusal and localizes current and historical supported
ranges in all nine cultures. Four private application-package/platform proofs
and affected matched-browser verification are now Complete at sourceece7813c.
The continuation milestone retains exact artifact identities, source-scoped
evidence reuse, original failures and required public-acquisition/full-CI/
ordered-delivery gates. No public or main/operator adoption is inferred.

## Context

The maintainer resumes the upstream catch-up goal through fixed ErsatzTV
`9c6b3deaca1feb0639134b880e8dd5eed225ee6d`. Row291 pins Next
`8c75907eb72b1160a55308348754bc666b45203c`, adding channel schema0.1.4 session
idle/readiness configuration. The terminal row296 pins
`6c9e0cf733f6439cc4f2a5f8ad763b3a31518797`, adding schema0.1.5 still-image cache
configuration. These are fixed dependency inputs inside the selected window;
this proposal does not chase a later branch tip.

Accepted Next025 uses basec5cb065 with twelve reviewed patches. Its ADR0131
indexed-reader extension already advertises schema0.1.4, but contains no
SessionConfig. Consequently0.1.4 alone cannot establish the new session
contract. Before this work Rust emitted no session block, owned idle expiry
externally and touched the worker heartbeat periodically without viewer demand.
The retained persisted real-host row291 regression fails with null instead of
default60.

The existing application UI already persists both global segmenter settings and
the channel's Keep Running choice. Upstream ignores initial readiness counts1–3,
honors4–10 and caps higher values at10; Keep Running sends idle0, otherwise
configured seconds with default60. These values must reach a worker which uses
them. A host-only replacement or a relabeled existing binary is insufficient.

## Decision

Prepare one consolidated local successor on exact Next6c9e0cf7. Independently
review every retained correction against unchanged unpatched regressions;
remove a patch only when the adopted upstream passes its retirement controls.
Preserve the ADR0131 index/lease/capability extension and all accepted caption,
selected-audio, single-use input, process ownership and hardware safety.

The indexed-reader addition must be versioned after upstream's schema0.1.5,
using0.1.6 for that additive extension. Negotiate the actual reader contract and
bind admission to executable identity; an old0.1.4 private reader cannot prove
session/cache support. Keep explicit older-reader compatibility scoped and
observable, without claiming the new session behavior for it. Complete-file
upstream configuration uses its actual supported session/cache schema.
Until the consolidated successor is qualified, session admission requires a
bounded, executable-identity-checked describe response with consistent channel
schema0.1.5 or later in the same breaking series and the expected ready/heartbeat
filenames. This deliberately excludes both meanings of0.1.4; it does not claim
that upstream8c lacks the feature. Reject before mutating the output folder.
Health applies the same contract check when enabled Next channels need it.

For capable workers, emit the saved session settings with source defaults,
omission and cap rules. Let the worker own idle expiry. The host translates real
viewer touches into heartbeat notifications, retains supervision, cancellation,
capacity, publication retries, callback revocation, on-demand checkpoints and
whole-process/producer cleanup. Isolated browser previews retain their existing
Stop On Disconnect policy even when the separate live channel keeps running;
finite standalone previews retain their completion/deadline ownership. Do not
keep an idle worker alive with a periodic
synthetic viewer heartbeat. Existing Native behavior and stored choices remain.

For cache-capable configuration, use the shared application-data/cache/next
root and explicit30 unused-day retention. The worker owns its still-images
subfolder; conversion does not create/delete files, and session output cleanup
must not discard the shared cache. Preserve Native's existing image/dynamic
filters and drawvg, as well as animated/media/canvas and time-dependent layers.
Require actual fixed-worker reuse, invalidation, fallback and bounded lifecycle
proof in R296-B before accepting the new runtime. Explicit legacy configuration
keeps its original schema and omitted cache/session extension.

Qualify the actual four required packages and application/runtime boundaries
before selecting an accepted successor. Preserve exact source/archive/lock,
patch, toolchain, companion and payload identities. Reuse valid evidence within
its unchanged scope; retain negative controls. Schema generation and source
contract tests remain mandatory. Native Linux/Windows, Linux ARM64/ARMv7
build/package/emulation, independent playback/transport, international tracks,
Health and affected matched-browser proof retain their existing obligations.
Native ARM, macOS and unavailable hardware retain approved deferrals.

Publication, managed adoption, application delivery and operator installation
retain their distinct authorization boundaries. Local candidates never overwrite
accepted packages or operator caches. No new runtime service, distribution
repository, paid runner, macOS work or application/Docker release is introduced.

## Consequences

One successor avoids rebuilding/requalifying intermediate Next pins. New worker
configuration and viewer ownership require integration and real-runtime proof;
serialization and a version label cannot establish acceptance. Row291's local
component and ordered row/window acceptance remain separate. The existing
ucu16-post-classic-continuation debt owns all remaining work; no duplicate
umbrella debt is created.

## Alternatives Considered

- Send session fields to the accepted025 worker: rejected because unknown fields
  are ignored and its private0.1.4 URI describes only the indexed extension.
- Keep host-only idle handling and readiness buffering: rejected because the
  agreed outcome requires the worker session controls and their actual behavior.
- Adopt each develop pin independently: rejected; qualify the fixed terminal
  successor once, while retaining individual ordered row applicability proof.
